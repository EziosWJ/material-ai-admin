# 领域语言

本文档定义“本地化智能材料写作平台”的统一领域语言，供前端、Java 后端和 Python AI 服务共同遵守。

统一领域语言的目标是减少业务沟通和代码命名中的歧义。页面文案、菜单、表格、表单、接口领域对象和文档应优先使用本文档中的中文术语。代码内部如需使用英文命名，应保持语义稳定。

## 术语总览

| 术语 | 推荐英文命名 | 含义 |
| --- | --- | --- |
| 材料 | `material` | 宣传文档的原始素材 |
| 片段 | `segment` | 材料切分后的文本块 |
| 来源片段 | `sourceSegment` | 检索命中并用于溯源展示的片段 |
| 写作任务 | `writingTask` | 用户发起的一次内容生成请求 |
| 问答 | `qa` 或 `questionAnswer` | 用户基于材料提出问题并请求大模型回答的一次交互 |
| Prompt 模板 | `promptTemplate` | 用于组装最终发送给大模型的模板 |
| 材料向量维护 | `materialVectorMaintenance` | Java 后端维护材料与片段向量一致性的对接能力 |

## 材料

材料是宣传文档的原始素材，由用户上传，由 Java 后端管理存储和元数据。

避免使用：

- 资料
- 文档
- `document`
- `resource`

说明：

- 前端页面中涉及用户上传的原始素材时，应称为“材料”。
- 文件上传只是材料进入系统的一种方式，不等于业务概念本身。
- 代码内部如需英文命名，优先使用 `material`。
- 与系统文件管理相关的底层文件对象可以继续使用既有 `file` 命名，但业务概念不应被替换为“文件”。

## 片段

片段是材料经切分后生成的文本块，带有元数据，用于向量检索。

避免使用：

- 分片
- `chunk`

说明：

- 对外展示尽量使用“片段”。
- 代码内部如必须使用英文，优先使用 `segment`。
- 片段通常由 Python AI 服务根据材料内容生成，但其生命周期和元数据应由 Java 后端统一编排。

## 来源片段

来源片段是一次检索命中并返回给写作任务或问答结果用于溯源展示的片段，包含正文、材料 ID、片段序号和相关度。

避免使用：

- `source`
- `hit`
- 检索结果

说明：

- 来源片段用于前端展示参考来源和溯源。
- 相关度可以用于排序、过滤、调试或低置信度提示。
- 相关度不一定直接展示给最终用户。
- 代码内部如需英文命名，优先使用 `sourceSegment`。

## 写作任务

写作任务是用户发起的一次内容生成请求，包含写作主题和期望输出类型。

输出类型包括但不限于：

- 提纲
- 初稿
- 润色稿
- 标题

避免使用：

- 生成任务
- 请求

说明：

- 写作任务由前端发起到 Java 后端。
- Java 后端负责业务编排、任务状态管理、调用审计和调用 Python AI 服务。
- 前端负责展示写作任务状态、输入条件、生成结果和来源片段。
- 代码内部如需英文命名，优先使用 `writingTask`。

## 问答

问答是用户基于材料提出问题并请求大模型回答的一次交互。

避免使用：

- `ask`
- `QA`
- 提问接口

说明：

- 对外页面和交互文案使用“问答”。
- 代码内部如需英文命名，优先使用 `qa` 或 `questionAnswer`。
- 问答请求必须先进入 Java 后端，由 Java 后端编排检索、调用和审计。

## Prompt 模板

Prompt 模板是用 Jinja2 编写的模板，根据写作任务和检索到的片段组装最终发送给大模型的提示词。

避免使用：

- 提示词模板
- `prompt`

说明：

- 对外配置和管理入口使用“Prompt 模板”。
- 代码内部如需英文命名，优先使用 `promptTemplate`。
- Prompt 模板的执行、渲染和模型调用不应由前端承担。

## 材料向量维护

材料向量维护是 Java 后端为保持材料与片段一致而调用 Python 服务写入、替换或删除向量的对接能力。

避免使用：

- 知识库 CRUD
- 材料 CRUD

说明：

- 材料向量维护不是普通材料增删改查，也不是前端直接操作知识库。
- 当前系统调用链必须保持为：前端调用 Java 后端，Java 后端调用 Python AI 服务。
- 前端可以展示维护状态、错误信息和审计结果，但不得直接调用 Python AI 服务执行向量维护。

## 命名建议

| 中文术语 | 推荐英文命名 | 不推荐命名 |
| --- | --- | --- |
| 材料 | `material` | `document`、`resource`、`file` |
| 片段 | `segment` | `chunk` |
| 来源片段 | `sourceSegment` | `source`、`hit`、`result` |
| 写作任务 | `writingTask` | `generateTask`、`request` |
| 问答 | `qa`、`questionAnswer` | `ask`、`QA` |
| Prompt 模板 | `promptTemplate` | `prompt` |

## 前端使用要求

- 菜单、页面标题、表格列名、表单标签、空态和错误提示应优先使用统一中文术语。
- 类型、API 方法、组件 props 如使用英文，应与推荐英文命名保持一致。
- 新增业务模块前，应先确认术语是否已在本文档中定义；未定义的新术语应补充文档后再大规模使用。
- 不要因为底层文件上传组件存在 `file` 命名，就把业务中的“材料”改称为“文件”。
